# 기능 1. 상품 목록 (`/products`)

> 공통 사양(기술 스택, 데이터 모델, 프로젝트 구조, 유틸)은 [`README.md`](./README.md)를 참조한다.

## 1. 개요
전체 상품을 그리드 형태로 한눈에 보여주는 화면. 각 상품 카드를 클릭하면 해당 상품 상세(`/products/[id]`)로 이동한다.

## 2. 사용자 스토리
- 사용자로서, 판매 중인 모든 상품을 목록으로 보고 싶다. 어떤 상품이 있는지 빠르게 훑기 위해서.
- 사용자로서, 관심 있는 상품 카드를 클릭해 상세 정보를 보고 싶다.

## 3. 대상 파일
- `src/app/products/page.tsx` — 목록 페이지
- `src/components/ProductCard.tsx` — 개별 상품 카드

## 4. 화면 / UI
- 페이지 제목: **"WOMEN"** (카테고리 페이지 타이틀).
- **서브카테고리 탭 바**: 상단에 노출 (시각만, **동작 없음**).
- **정렬 옵션 바**: "신상품순" 표기 (시각만, **동작 없음**).
- **상품 그리드**: 반응형 그리드로 카드 나열.
  - 모바일 2열 / 데스크톱 4열 (`grid-cols-2 lg:grid-cols-4 gap-x-4 gap-y-10`).
- **상품 카드(`ProductCard.tsx`)** 구성:
  - 상품 이미지 (`imageUrl`) — `next/image`, 정사각(1:1) 또는 4:3 비율 고정, `alt`=상품명.
  - 상품명 (`name`).
  - 가격 (`price`) — `formatPrice` 사용, `12,000원` 형식.
  - 카드 전체가 `/products/[id]`로 이동하는 링크(`next/link`).

## 5. 동작 규칙
- 데이터는 `src/data/products.ts`의 `products` 배열을 import 하여 렌더링.
- 상품 8개이므로 페이지네이션·무한스크롤 없음.
- 카드 클릭 시 `product.id` 기반 라우팅(`/products/${product.id}`).

## 6. 수용 기준 (Acceptance Criteria)
- [ ] `/products` 접속 시 8개 상품이 모두 카드로 표시된다.
- [ ] 각 카드에 이미지·상품명·가격(콤마 포맷)이 표시된다.
- [ ] 카드를 클릭하면 해당 상품의 `/products/[id]`로 이동한다.
- [ ] 데스크톱 4열 / 모바일 2열로 반응형 배치된다.
- [ ] 모든 이미지에 `alt`(상품명)가 지정된다.
